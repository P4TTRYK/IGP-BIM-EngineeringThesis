## Prerequisites

- uv
- nodejs

## Usage

### clone `git clone` or download .zip

### Start backend api server

- go to /app/api
- install pyproject
- `uv sync`
- `uv run python -m flask --app main run`

### Start

- go to /app/xeokit
- `npm install`
- `npm run dev`
- enjoy
